## Final Project Presentation Assignment

### Project Presentation Dates

The project presentations will take place on **June 4, June 11, and June 18**, during regular class hours. We will attempt to conduct the presentations in the laboratory. However, if this is not possible, they will be held in the classroom, accompanied by the corresponding video demonstration.

### Activities for the Final Project Presentation

Each group must prepare an oral presentation about its final project. The presentation should include the following components:

1. **Application Context and Problem Statement**
   Students must explain the context of the application, including the problem being addressed. They should describe the measurement requirements associated with the variable or variables to be measured, as well as the way in which the information obtained from the measurement or control system is used.

2. **Technical Description of the Implemented Solution**
   Students must present the implemented solution from a technical perspective. This should include an explanation of how the selected sensors satisfy the requirements of the application, considering their dynamic, static, and mechanical characteristics, including installation considerations. The presentation should also describe the complete proposed implementation, the required signal conditioning, the simulations performed, the code developed, and a demonstration of the implemented prototype or experimental setup.

3. **Presentation Format**
   Each group must prepare a presentation with a maximum duration of **15 minutes**, followed by **5 minutes for questions**. All groups must upload their presentation slides before the first presentation session.

### Evaluation Criteria

The project presentation will be evaluated according to the following criteria:

* Mastery of the topic and clarity of the oral presentation.
* Completeness and quality of the content, including simulation results.
* Group cohesion and balanced participation among members.
* Quality, organization, and clarity of the presentation slides.

### Note

Only **one member of each group** is required to upload the presentation.
